# Restaurant Menu Item Discovery
Restaurant Menu Item Discovery is a web application that helps restaurant owners explore new menu ideas through dish searches. Users can search for a specific dish, such as curry chicken, and discover meal inspiration using external API data.

## Live Demo 
[Try out the Restaurant Menu Item Discovery!](https://nasa-api-88tq.onrender.com/)


## Features
- **Dish Search**: Search for dishes by name or food type
- **Menu Inspiration**: Discover meal ideas to inspire new restaurant menu offerings
- **Dynamic Results**: Display meal information based on search queries
- **Simple Interface**: Easy-to-use search functionality

## Tech Stack & APIs
- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON
- Meal API

## Getting Started
**Installation**

1. Clone the repository:
```bash
git clone https://github.com/CarlyJovon/restaurant-api.git
```
2. Navigate to the project directory:
```bash
cd restaurant-api
```
3. Open the project using a local development server, such as VS Code Live Server.
Enter a dish in the search field and select Search to explore menu inspiration.
